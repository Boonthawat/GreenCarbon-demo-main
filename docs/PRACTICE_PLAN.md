# แผนซ้อมแข่ง: เขียนระบบ 7 ชั่วโมง + ตรวจระบบ 1 ชั่วโมง

ใช้กับวันที่ 2 ของการแข่งขัน (ออกแบบและพัฒนาเว็บแอปพลิเคชัน 8 ชั่วโมง) ตามเกณฑ์รายการที่ 62
ระบบที่ซ้อมคือ GreenLoop ในโฟลเดอร์นี้: **เว็บ PHP + MySQL (10 ตาราง) + CSS**

ฟังก์ชัน Green: แจ้งรีไซเคิลขยะอิเล็กทรอนิกส์พร้อมรูปสินค้า ประเมิน CO₂e และรับแต้ม
ส่วนเสริม: รูปโปรไฟล์ การแจ้งเตือนทั้งสมาชิกและผู้ดูแล

## ข้อจำกัดในห้องแข่งที่ต้องซ้อมให้เหมือนจริง

- ห้ามนำเอกสาร แฟลชไดรฟ์ และเครื่องมือสื่อสารเข้าห้อง จึงต้อง**จำโครงและพิมพ์จากความเข้าใจ** ไม่ใช่ลอกโค้ด
- ทีมมี 3 คน แต่มีคอมพิวเตอร์ 2 เครื่อง และต้อง Format เครื่อง ลงโปรแกรมเองในวันแรก
- ไม่มีอินเทอร์เน็ต ใช้ได้เฉพาะ library ที่เจ้าภาพเตรียมให้ ระบบนี้ใช้แค่ Bootstrap 5 กับ Chart.js
- VS Code ห้ามลง Extension เพิ่ม ให้ซ้อมด้วย VS Code เปล่า
- เตรียมไฟล์รูปไว้ทดสอบการแนบรูปไม่ได้ ให้ใช้ Photoshop หรือ Paint ในเครื่องสร้างรูปทดสอบเอง
